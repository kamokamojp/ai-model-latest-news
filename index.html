OpenAIの10月28日付とGoogle・xAIの10月27日付の公式記載を確認。いずれも日付だけで、前号締切より後の掲載かは確定できません。

号の日付：2026年10月29日（日本時間） 予定確認時刻：08:00 JST 調査基準時：08:40:27 JST

OpenAI：ChatGPT契約者向けの無料APIクレジット

10月28日付のOpenAI資料では、対象のChatGPT ProおよびBusiness契約者が月額最大500ドルの無料APIクレジットを請求できると記載。Proは枠に応じて100ドル・200ドル・500ドル、Businessは席あたり月20ドル（Standard）・100ドル（Premium）で、ワークスペース上限は月500ドルです。初回は日割り、未使用分は期間末に失効します。

Google：Gemini API CLI（ベータ版）

10月27日付のGoogle資料では、Gemini API CLI（gemini-api）のベータ版を掲載。状態を持たない・依存関係なしのシェル用クライアントで、文章やメディアの生成、ファイルの分析、管理対象エージェントの実行ができます。

xAI：テキスト要請への内容ガイドライン指定

10月27日付のxAI資料では、テキストAPI要請にguidelines配列でnsfw・暴力・冒涜表現の扱いを指定できると記載。新しいモデル発表ではなく、APIの振る舞い設定の追加です。

前号の内容は再利用しない

アリババの最新は前号扱いの10月27日付のままです。そのため、Qwen音声モデルを新しい発表として繰り返していません。

範囲と限界

OpenAI、Google、Alibaba/Qwen、Mistral、Anthropic、xAI、DeepSeek、Cohereの選定公式ページを確認。Cohereの変更履歴ページは取得したテキストに日付が含まれておらず、10月28日・29日付の項目を確認できませんでした。全社・全配信先の網羅ではありません。カバレッジ記録も参照してください。
