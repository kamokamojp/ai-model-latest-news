OpenAIのモデルがGoogle Cloud Model Gardenへ

OpenAIとGoogle Cloudは、OpenAIのモデルとCodexワークフローをGoogle Cloud Model Gardenに加える提携を、10月21日付の公式記事で発表しました。記事本文には公開時刻の記載がありません。Google Cloud公式X投稿のDOMには2026-10-21T13:19:54Z（UTC）のtimestampがあります。記事の掲載日とX投稿時刻は別々に記録しています。Google Cloudによると、「GPT-Astra」「GPT-6.1 Sol」「GPT-6 Luna」は一部の企業顧客向けにプライベートプレビューとして展開中です。OpenAI側の記事は一般提供を「今後数週間」と案内しており、現時点で一般提供開始とは言えません。

Google Cloud API経由の利用に加え、ローカルのCodex CLI/DesktopからGeminiプラットフォームへ接続する手順も発表されています。購入はGoogle Cloud Marketplace経由で、既存のGCP支出コミットから充当できると両社は説明。Google Cloudは請求を単一のGoogle Cloud請求書にまとめ、Flexible Savings Plansにも算入すると記しています。Googleは「別のベンダー契約は不要」と説明しますが、告知は個別契約条項までは掲載していません。

名前には注意が必要です。Google Cloudの告知は一つ目を「GPT-Astra」と表記します。一方、OpenAIの直販APIモデルカタログでは「GPT-6 Astra」、IDは gpt-6-astra です。Google Cloudの告知にはModel Garden用の固有API IDやendpointはありません。名前の似た直販API IDを、Cloud previewのIDとして推測しません。

料金や利用枠も分けて考えます。OpenAIの直販APIカタログには、Astraが入力10ドル・出力50ドル、Solが2ドル・10ドル、Lunaが0.10ドル・0.50ドルとあり、単位はいずれも100万トークンあたりです。これはOpenAI APIの参考価格で、Google Cloud previewの価格ではありません。Google Cloudの告知と確認したVertex AI料金ページからは、previewの個別価格・課金単位、地域、rate limitを確認できませんでした。導入前にCloud側の最新条件を確認してください。

データ保護についてGoogle Cloudは、プロンプトや文脈、出力を指定されたデータ境界内に留めて基盤モデルの学習に使わないと説明しています。Zero Data RetentionとConfidential Computeは、告知では今後提供予定です。これは提供元の説明であり、独立監査の結果として扱っていません。ライセンスやウェイト公開についても、今回の告知では確認できません。

ElevenLabs、リアルタイム音声翻訳を企業向けalphaに

ElevenLabsは10月21日付の記事で、音声通話の双方がそれぞれの言語で話し、相手の言語で聞ける「Eleven Realtime Translation」を発表しました。時刻・タイムゾーンは記載されていません。提供形態はElevenAPIの企業顧客向けalphaです。記事はEleven v4 Turboを利用し、自動言語検出、90を超える言語、17,500を超える声を説明していますが、これらは会社発表の仕様です。記事には一般利用向け価格、提供地域、rate limit、安定したモデルIDは記載されていません。独立した性能比較も確認していません。

OpenAI APIの運用機能更新

OpenAI APIの10月21日付changelogには、プロジェクトが使えるservice tierをPlatform設定で制限できる機能が追加されました。10月20日付にはResponses APIの12時間prompt cachingが記載され、長時間空いたリクエストでも共通の指示などをキャッシュできます。cache writeの料金は入力トークン価格の2.5倍と説明されています。これはAPIの運用・料金機能の更新で、新モデルの発表ではありません。

ほかの公式ページも確認

Anthropic公式一覧の最新モデル掲載はHaiku 5.5（10月7日）。Mistralのニュースページで最新のモデル関連告知はVoxtral 3（10月20日）、Cohereの更新欄はRerank 5（10月21日）で、いずれも前号で扱いました。xAIのモデル関連最新表示はGrok Voice 3.0（10月14日）とGrok 4.7（9月21日）。DeepSeekの公式更新欄は10月17日付で、V4.1 Flash更新とSearch/Fetch APIを掲載しています。DeepSeekが示すベンチマーク値は同社の報告であり、独立検証とは区別します。

以上は、下記の各社公式ページで確認した範囲です。確認範囲外に発表がないという断定ではありません。
