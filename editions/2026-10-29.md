## OpenAI：ChatGPT契約者向けの無料APIクレジット

OpenAIのAPI changelogは10月28日付で、対象のChatGPT ProおよびBusiness契約者が月額最大500ドルの無料APIクレジットを請求できると記載しています。詳細ページでは、Proは100ドル枠・200ドル枠・500ドル枠に応じて100ドル・200ドル・500ドル、BusinessはStandard席あたり月20ドル、Premium席あたり月100ドルで、ワークスペース全体の上限は月500ドルとしています。初回付与は当該請求期間の残りに応じた日割りで、未使用分は請求期間の終わりに失効し、翌期間へ繰り越しません。申請条件は、7日以上継続した有料契約であること、契約とAPI組織の両方の所有者であること、ChatGPTとAPIで同じメールアドレスを使うことです。対象となる利用にはResponses API、Agents API、Decisions API、GPT-LiveやRealtime API、Images API、内蔵ツールなどが含まれます。APIキー経由のCodex利用は対象外で、この特典でChatGPTやCodexの利用上限が増えることもありません。新しいモデル発表ではなく、API利用の特典である点に注意してください。

## Google：Gemini API CLI（ベータ版）

GoogleのGemini APIリリースノートは10月27日付で、Gemini API CLI（`gemini-api`）のベータ版を掲載しています。詳細ページでは、シェルから直接Geminiを呼び出すための、状態を持たない・依存関係なしのコマンドラインクライアントと説明されています。Interactions API上で動き、文章やメディアの生成、ファイルの分析、管理対象エージェントの実行ができます。コマンドには画像・音声合成・音楽・動画・文章生成・分析・文字起こし・エージェント管理などがあり、認証にはGoogle AI Studioで作成したAPIキーを使います。ベータ版の提供であり、正式版（GA）とは記載されていません。
